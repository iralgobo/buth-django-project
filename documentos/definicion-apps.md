| App          | Objetivo                                                                |
| ------------ | ----------------------------------------------------------------------- |
| `markets`    | Configuración de pares, mercados (spot/futuros) y timeframe.            |
| `candles`    | Almacenamiento de velas OHLCV obtenidas de Bitunix.                     |
| `strategies` | Definición de estrategias de trading, motor de backtesting y ejecución. |
| `risk`       | Estrategias y reglas de gestión de riesgo.                              |
| `trading`    | Logs de operaciones, ejecución de órdenes y estado de cuenta.           |
| `tasks`      | Cron/Celery tasks para sincronizar velas y ejecutar estrategias.        |
